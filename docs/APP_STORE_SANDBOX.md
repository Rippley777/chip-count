# Sandbox acceptance and App Review

## Reviewer flow (no developer tools required)

Install and open Chip Count. On the empty Live screen click **Explore demo** (also available under Sources → Explore demo workspace). The demo runs entirely inside the installed app using a separate in-memory index. Inspect sessions, analytics, projects, comparison, and budgets; export a CSV or JSON using the native save panel. Return to your own data using the demo banner. No account, AI tool, API key, development environment, or server is required.

For real logs, open **Sources → Add source**, choose Claude Code or Codex, then **Choose folder**. The picker shows hidden folders. Press Shift-Command-G and enter `~/.claude/projects`, `~/.codex/sessions`, or `~/.codex/archived_sessions`. Choose the folder, name the source, and connect. Claude's alternate configuration directory or a custom provider directory can be selected in the same way. Choose directories for ongoing monitoring and rotation; **Import JSONL** grants access to one selected file, whose bookmark follows that file if it is renamed. Paths are shown for orientation; only native selection grants access. Unavailable sources remain listed and can be reconnected with Configure source → Choose folder, disabled, or removed. Chip Count leaves the original logs unchanged.

## Release gate

Run this matrix against `npm run appstore:local` and repeat on the signed distribution/TestFlight app. Record OS, build, date, evidence and any sandbox-denial diagnostics. Do not mark a row passed based on unit/browser tests. No production signing identity or provisioning profile is included in the repository.

## Automated checks

`cargo test -p chip-core` covers path-grant separation, migration from path-only indexes, restart without grants, append, rotation, revoke/regrant, rebuild, bookmark privacy/removal, and source-byte preservation. `cargo test -p chip-count --no-default-features --features app-store` checks native boundary validation. `npm run test:appstore` checks signing/profile rejection rules. `npm test` covers browser flows, including the separate demo workspace. These checks complement the matrix above; they do not exercise Apple's sandbox extensions or sleep/wake.

## Local evidence — October 4, 2026

Tested the ad-hoc signed `labs.rippley.chip-count.sandbox-test` app on macOS 15.1.1 (arm64), with no development servers running. Native UI verification confirmed:

- The empty app starts with no discovered roots; native NSOpenPanel selects a disposable Claude JSONL directory and the source becomes healthy.
- Initial usage is 110 tokens. After full quit, external append, and relaunch, the stored bookmark reopens without a picker and usage reaches 320 tokens. External rename/rotation plus a replacement JSONL reaches 630 tokens automatically.
- Moving the selected directory updates its path through bookmark resolution. Removing the disposable root leaves it listed as unavailable with reconnect instructions. Native re-selection of a preserved copy restores healthy access.
- Finder selects the actual indexed `session.jsonl` through NSWorkspace. NSSavePanel saves a 15,544-byte CSV outside the source roots. SHA-256 hashes of both fixture logs remain identical to the external writer's expected hashes after scans, restart, rotation, reveal, and export.
- Settings shows launch at login disabled/off. Explore demo workspace shows separate Claude and Codex sample sources in the installed sandbox app.

Automated checks pass: 62 core tests, two native-boundary tests, 16 browser tests, three App Store signing/profile checks, and five existing Developer ID workflow checks. Frontend build/lint and Rust Clippy pass for both variants.

**Remaining release evidence:** actual machine sleep/wake, OS/TCC permission revocation (the local test exercised a missing root), fresh native selection of Codex roots/individual JSONL, and repeat acceptance on the signed App Store/TestFlight app. Distribution signing/profile/installer steps require the distributor's credentials and have not been executed. The matrix remains the submission gate.
